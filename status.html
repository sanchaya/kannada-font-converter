ಪರಿವರ್ತನೆ ಸ್ಥಿತಿ

ಪ್ರತಿ ಫಾಂಟ್‌ಗೆ ನಾವು 2,077 ಟೆಸ್ಟ ಕೇಸ್‍ಗಳನ್ನು (ಪರೀಕ್ಷೆಗಳು) ನಡೆಸುತ್ತೇವೆ - ಎಲ್ಲಾ ವ್ಯಂಜನ × ಸ್ವರ ಚಿಹ್ನೆ ಸಂಯೋಜನೆಗಳು, ಹಲಂತ ರೂಪಗಳು, ಅನುಸ್ವಾರ/ವಿಸರ್ಗ, ಎಲ್ಲಾ ಒತ್ತಕ್ಷರ (ಸಂಯುಕ್ತಾಕ್ಷರ) ಜೋಡಿಗಳು, ನಿಜವಾದ ಪದಗಳು, ಮತ್ತು ಇಂಗ್ಲಿಷ್/ಸಂಖ್ಯೆ ಮಿಶ್ರಿತ ಪಠ್ಯ. ಪ್ರತಿ ಪ್ರಕರಣ Unicode → ASCII → Unicode ಸುತ್ತು ಪೂರೈಸಿ ಮೂಲಕ್ಕೆ ಸಮನಾಗಬೇಕು.

Unicode → ASCII (u2a) ವೈಫಲ್ಯ = ಕನ್ನಡ ಅಕ್ಷರ ASCII ಗೆ ಪರಿವರ್ತನೆಯಾಗದೆ ಉಳಿದಿದೆ; ASCII → Unicode (a2u) ವೈಫಲ್ಯ = ASCII ಸರಿಯಾಗಿ ಬಂದರೂ ಹಿಂತಿರುಗಿ ಪರಿವರ್ತಿಸಿದಾಗ ಮೂಲ ಪಠ್ಯ ಸಿಗಲಿಲ್ಲ. ಕೊನೆಯ ಪರೀಕ್ಷೆ: -
